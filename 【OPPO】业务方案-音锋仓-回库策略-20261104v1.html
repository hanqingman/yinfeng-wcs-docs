1. 业务处理方式

适用于入库、盘点回库、隔离筛选回库、出库余料回库、理货回库、呼叫出库后回库等工作台到库位的搬运。

项目入库业务其他业务回库
数量来源首托 LPN 获取整单组盘明细，统计托盘数量当前托盘＋有可用库存的同类待回库托盘数量，排除入库业务托盘
货道计算首托触发整单规划每托投线重新计算
搬运任务生成与响应按托数预建“新建”搬运任务，指定货道、暂不绑定 LPN。RCS 扫码申请时，按轨道评分选择同组搬运任务绑定 LPN，满足货道锁及顺序后执行并响应。RCS 扫码或按物理按钮申请时，为当前 LPN 新建搬运任务、指定货道，并直接在响应中返回 RCS。
后续处理使用剩余规划搬运任务根据最新状态重新匹配

“同类”指外部单号＋供应商＋SKU均一致。已分配搬运任务的托盘计入货道占用，不重复纳入待分配托数。

同类待回库托盘按扣除预占后的可用库存统计：无可用库存的托盘不计入，包括被出库或理货出库整托预占的托盘；部分预占后仍有可用库存的托盘计为1托。

2. 托盘类型与存放条件

  • 混托：同一托盘包含不同外部单号、供应商或 SKU。
  • 非混托：同一托盘的外部单号、供应商、SKU 均一致。
库区存放条件
多板区同一货道仅存放同一外部单号、供应商、SKU 的托盘。
单板区同一货道允许存放不同物料的非混托托盘。
混托区允许存放混托和非混托托盘。

货道容量读取实际配置，支持未来新增进深。

3. 共用货道匹配算法

混托

仅在混托区查找：

  1. 优先选择可用空货道。
  2. 无可用空货道时，选择货道可用容量最大的非空货道。
  3. 同等容量条件下，按轨道评分择优。
  4. 无可用货道时拦截，门型 LED 报错。

非混托

仅剩1托：同类待分配托盘仅剩1托时，优先分配1板区，无可用位置时再分配混托区；混托区仍无可用位置时，门型 LED 报错。

同类待分配数量大于1托时，在符合条件的多板区货道中匹配：

  1. 非空货道优先：先匹配已有同类托盘的非空货道，不足部分再使用空货道。
  2. 逐次容量匹配：先找货道可用容量等于待分配托数的货道；无相等容量时，选择货道可用容量大于待分配托数且最小的货道；无单条货道能够容纳时，选择货道可用容量最大的货道，容纳部分托盘，再对剩余托盘重复匹配。
  3. 轨道评分择优：同等容量条件下，按轨道评分选择。

优先级：存放条件 → 非空优先 → 容量匹配 → 轨道评分。

4. 轨道评分

综合搬运任务负载、空货道率和 SKU 分布评分，分数越高越优先。同等候选条件下，优先选择当前 SKU 托盘较少的轨道，使同 SKU 分散存放，支持从不同轨道出库，提高出库效率。

轨道评分＝（1－搬运任务繁忙率）× 权重A＋空货道率 × 权重B＋（1－SKU 托盘占比）× 权重C
指标计算口径
搬运任务繁忙率轨道已分配未完成的搬入、搬出、移库搬运任务数 ÷ 轨道搬运任务负载基准。
空货道率轨道候选范围内空货道数 ÷ 轨道总货道数。
SKU 托盘占比该轨道当前 SKU 的托盘数 ÷ 所有可参与该 SKU 存放的轨道中该 SKU 的托盘总数。分母统计范围不随本次容量匹配后的候选轨道范围变化。托盘数包含实际在库及已规划或已分配未到位的托盘，按托盘去重；总数为0时取0。占比越低，评分越高。

轨道评分用于货道匹配时同等容量候选之间的选择，以及入库投线时同组未绑定搬运任务之间的 LPN 分配。

5. 入库整单规划与逐托绑定

首次投线

  1. RCS 扫码识别首托 LPN，发起第一段搬运任务申请；WCS 根据 LPN 获取整单组盘明细，统计本次应搬入托盘。
  2. 区分混托；非混托按同类分组。
  3. 调用共用算法，规划目标货道。
  4. 按托数预建“新建”状态的搬运任务，指定货道，暂不绑定 LPN，保存在 WCS。
  5. 预留规划容量。

逐托投线

  1. RCS 扫码识别当前 LPN 并申请搬运任务；WCS 找到所属组尚未绑定的搬运任务。
  2. 按目标货道的最新轨道评分选择搬运任务，绑定 LPN。
  3. 满足货道锁及执行顺序后，执行已绑定 LPN 的搬运任务，并通过第一段申请响应向 RCS 返回搬运任务信息。
  4. 第二段请求时确定深度；完成反馈后更新库存位置。

首托同样执行绑定流程。后续托盘沿用已有规划，最后一个 LPN 投线时绑定剩余搬运任务。

6. 其他业务逐托动态分配

  1. RCS 通过扫码或物理按钮发起搬运任务申请，携带当前 LPN、源位置；WCS 获取托盘实际库存。
  2. 统计当前托盘及有可用库存的同类待回库托盘数量，排除入库业务托盘及无可用库存的托盘（含整托预占）。
  3. 根据最新容量、货道锁及轨道评分，调用共用算法。
  4. 仅为当前 LPN 创建“新建”状态的搬运任务，记录目标货道及容量占用，然后通过本次第一段申请响应直接返回 RCS 搬运任务。
  5. 第二段申请时确定深度，完成反馈后更新库存位置。
  6. 下一托投线时重新统计、重新匹配。

7. 容量占用与搬运执行

申请与响应：RCS 通过扫码或物理按钮申请搬运任务。入库业务绑定并执行预建搬运任务后响应；其他业务回库为当前 LPN 新建搬运任务后直接响应。响应包含任务号、LPN、母车轨道编号及货道编号。

货道可用容量＝货道配置容量－实际占用－已规划或已分配未到位占用

货道可用容量指该货道当前还能接收的托盘数量。

  • 入库预建搬运任务时预留容量，绑定 LPN 时沿用原占用。
  • 其他回库确定当前托盘目标后，占用对应容量。
  • 多板区同时校验已存托盘和已规划托盘的同类条件。
  • 搬入完成后，将预留占用转为实际占用；搬运任务撤销或规划调整时同步更新。
  • 实际执行按《音锋仓货道锁方案》取得或接入搬入锁，同一货道逐托搬运。
  • 已返回 RCS 的搬运任务保留目标货道。

8. 分配样例

条件匹配结果
混托：有空货道，也有剩余2位的非空货道。优先空货道。
混托：无空货道，非空货道分别剩余1、2位。选择剩余2位的货道。
非混托：待分配3托，同类非空货道剩余2位，空货道容量3位。先使用非空货道2位，再匹配剩余1托。
非混托：待分配5托，无可用非空货道，候选货道可用容量为3、5、6位。选择可用容量5位的货道。
非混托：待分配8托，无可用非空货道，候选货道可用容量为3、4、5、6位。先选可用容量6位的货道，剩余2托再选可用容量3位的货道。
同等容量的两条候选货道分属不同轨道。选择轨道评分较高的货道。
同类待分配仅剩1托，1板区、混托区均无位。拦截，门型 LED 报错。
